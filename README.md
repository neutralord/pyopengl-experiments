pyopengl-experiments
====================

This repo contains a subset of code samples from [The OpenGL® Programming Guide](http://www.opengl-redbook.com/) (widely-known as the Red Book) translated from C++ to Python 3.2.

#### UPD 2026.
Nowadays, OpenGL is more of a part of history than a modern technology, and despite the fact that GLSL is still used quite widely — you should think twise about your motivation before deciding to use it instead of one of its successors (WGSL, Slang, and so on).

If you have a strong motivation to learn GLSL, take into account that the complete set of examples from the Red Book is now available in the [official examples repo](https://github.com/openglredbook/examples) — just use your favorite LLM to translate it into the language of your choice.
